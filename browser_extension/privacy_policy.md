# Privacy Policy - VaultMate Browser Extension

**Last Updated:** September 28, 2025

## Overview
VaultMate Browser Extension automatically captures login credentials from websites and syncs them securely with your local VaultMate app.

## Data Collection
- **Login Credentials:** Username, password, website URL, domain
- **Form Metadata:** Capture timestamp, form type (login/registration)
- **Usage Statistics:** Capture counts, sync status

## Data Storage
- **Local Only:** All data is stored locally on your device
- **No Cloud Storage:** No data is sent to external servers
- **Encryption:** All passwords are encrypted using AES-256
- **Local Sync:** Data syncs only with your local VaultMate app via localhost

## Data Sharing
- **No Third Parties:** We do not share data with third parties
- **No Analytics:** No usage data is sent to external services
- **No Tracking:** No user tracking or profiling

## User Control
- **Toggle Control:** Enable/disable auto-capture anytime
- **Data Management:** View, edit, or delete captured credentials
- **Complete Removal:** Uninstalling removes all extension data

## Security
- **Local Processing:** All processing happens on your device
- **Secure Communication:** Extension communicates only with local VaultMate app
- **No Network Requests:** No external network requests for credential data
